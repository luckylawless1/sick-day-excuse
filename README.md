A [make.fun](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36) bounty entry: a program that writes one line — the funniest sick-day excuse — to `/output/entry.txt`.

## The entry

> Can't come in today — my smartwatch thought I fell, called an ambulance, and now I'm stuck at home explaining to a paramedic that I was only napping.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the entry to `/output/entry.txt`.
